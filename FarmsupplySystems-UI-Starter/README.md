# S.T.P.B Farm Supplies & Equipment — UI Starter

Phase 1 frontend prototype using plain HTML, CSS, and JavaScript.

## Files
- `index.html` — dashboard and navigation shell
- `styles.css` — forest-green / cream styling and responsive layout
- `app.js` — sidebar navigation and preview interactions

## Run
Open `index.html` in a browser, or use VS Code Live Server.

## Notes
Dashboard totals, chart values, customers, and transaction rows are sample display data only. Authentication, Supabase, CRUD, inventory calculations, and reports are not connected yet.

## Vercel
Import the GitHub repository. Select **Other** as the framework preset, leave the build command blank, and use the repository root as the output directory.
